# 小程序设备验收记录

本文用于任务 18.3 的微信开发者工具 iOS/Android 模拟器验收，以及任务 18.5 的真实设备验收。验收结果必须来自实际运行环境，静态检查和 Node.js 契约测试仅作为前置条件。

## 项目设置

- 导入目录：项目根目录，`miniprogramRoot` 为 `miniprogram/`。
- 编译类型：微信小程序。
- 基础库版本：`2.33.0`。
- 页面注册：`miniprogram/app.json`，共 36 个用户可见页面。
- 原生 TabBar：首页、功能、成长、我的。

每轮验收记录微信开发者工具版本、基础库版本、设备模型、系统版本、网络模式、测试账号类型和验收时间。账号记录只写用途标签，不写账号、密码、令牌或 Cookie。

## 前置检查

```bash
npm run lint
node scripts/test-miniprogram-core-ui-structure.js
node scripts/test-miniprogram-page-states.js
node scripts/test-miniprogram-long-content-keyboard.js
npm test
```

全部命令通过后开始模拟器验收。测试数据至少准备以下状态：

1. 游客或登录失效状态。
2. 已登录且没有孩子档案。
3. 已登录且只有一个孩子档案。
4. 已登录且有两个不同年龄段的孩子档案。
